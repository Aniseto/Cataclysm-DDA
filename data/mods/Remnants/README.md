# Remnants

Remnants is a story-focused survival mod scaffold for Cataclysm: DDA.

## Current skeleton
- `modinfo.json`: registers the mod.
- `scenarios.json`: adds a dedicated scenario that starts in a house.
- `snippets.json`: contains narrative text snippets for early story flavor.
- `DESIGN_PLAN.md`: planning document and roadmap.

## Next implementation steps
1. Add custom profession(s) linked to the scenario.
2. Add mission and dialogue progression for chapter 1.
3. Add EOC-driven story state (chapter flags, branch flags).
4. Add mapgen/start-location constraints if you want one exact house layout.
5. Add narrative rewards and fail states per chapter.
